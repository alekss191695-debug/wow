# Trinity Creator — русский перевод

Trinity Creator — это интерфейс для работы с базой данных, помогающий разработчикам серверов World of Warcraft создавать предметы, существ, задания и другой контент.

Программа подходит как начинающим, так и опытным разработчикам и поддерживает различные эмуляторы от Vanilla до Wrath of the Lich King. Можно добавить поддержку пользовательских эмуляторов, отдельных версий или репаков.

## Перед загрузкой

Trinity Creator — **не чит**. С его помощью нельзя добавлять предметы на приватный сервер, на котором вы играете. Программа предназначена для администраторов серверов и разрабо��ки пользовательского контента.

## Начало работы

- [Скачать и установить последнюю версию](https://github.com/NotCoffee418/TrinityCreator/releases/latest)
- В верхнем меню выбрать эмулятор.
- Ввести данные базы данных и каталог DBC (необязательно; добавляет дополнительные возможности).
- Начать создание контента.

**Примечание:** чтобы увидеть созданный контент в игре, обновите таблицы или перезапустите сервер.

## Поддерживаемые эмуляторы

- TrinityCore WotLK 3.3.5a (база данных 2020-01)
- TrinityCore WotLK 3.3.5a (база данных 2016-06)
- AzerothCore WotLK 3.3.5a
- cMangos WotLK 303.5a (последняя собранная версия)
- Light's Hope Emulator 1.12.2 (репак Brotalnia v16)
- VMaNGOS 1.12.2 (репак Brotalnia v17)

**Обновление v1.1:** инструмент создания профилей позволяет добавить поддержку любого эмулятора для WotLK и более ранних версий. Также стало проще редактировать существующие профили для немного более новых или старых версий эмулятора.

Известные ограничения: некоторые поля предназначены специально для эмуляторов версии 1.12. При этом в Cataclysm и более новых версиях WoW могут возникнуть проблемы.

Созданные профили можно предложить проекту [NotCoffee418/TrinityCreatorProfiles](https://github.com/NotCoffee418/TrinityCreatorProfiles).
